# Responsible use and reporting

## Purpose

This project exists to improve detection of tunnelling tools. Its content is for defence,
authorised security testing and education.

## What the project will not publish

- Instructions for operating the tools against systems.
- Modified, packed or obfuscated versions of any tool.
- Data from systems the contributor does not own.

## Reporting a problem

Open an issue if you find any of the following in this repository:

- sensitive data in an evidence file,
- content that goes beyond the scope above,
- a result you believe is wrong.

For sensitive data, say only which file is affected. Do not quote the data in the issue.
