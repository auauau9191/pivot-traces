# Evidence

Logs and packet captures behind every claim in this repository.

- Naming: `<tool>_<version>_<os>_<scenario>_<variant>.<ext>`
- Baselines: `baseline_<os>_<date>.<ext>`
- Keep single files small. Trim captures to the relevant session.
- Sanitise before commit. Lab IP ranges only. No real hostnames, usernames, keys or tokens.
- Nothing from client networks or training-provider labs.
